# traps/page-constructor — `@gravity-ui/page-constructor`

- **Конфиг блока — из установленного пакета:** `node_modules/@gravity-ui/page-constructor/build/esm/editor/data/templates/<block>.json` (рабочая структура), формы пропов — `…/build/esm/models/constructor-items/{blocks,sub-blocks}.d.ts`; usage-доки `memory-bank/usage/<camelCase>.md` покрывают не все блоки — нет доки → шаблон + `.d.ts`, не ретрай 404.
- **Хост обязан дать глобальный `box-sizing: border-box`** (сетка его молча предполагает; иначе оверфлоу на всех ширинах и карточки 2-в-ряд) — reset в `templates/app-shell/README.md`; errata #7.
- `theme` карточек — `default`/`light`/`dark` (не `normal`). `PriceCard` (`PriceDetailed` deprecated): `theme` красит только текст, фон — `backgroundColor`; `theme:'dark'` без тёмного фона = белый текст на прозрачном. Выделение плана — `border: 'line'` (тип `'shadow'|'line'|'none'`, не boolean) или тёмный `backgroundColor` + `theme:'dark'`.
- **Кнопки на тёмном блоке** (`theme:'dark'` у header-block/секции): блок не оборачивает в `g-root_theme_dark`, uikit-кнопка берёт светлую тему → `outlined`/`normal` нечитаемы; бери `*-contrast` (`outlined-contrast` / `flat-contrast` / `normal-contrast`).
- `slider-block`: плоский массив сабблоков из `templates/slider-block.json`; `slidesToShow` — число или `{sm,md,lg,xl}` (не `{desktop,tablet,mobile}`); требует `import 'swiper/css'` в entry. Слайдер — когда набор не влезает; влезает (3–6) → `card-layout-block`.
- Карточки с большой боковой картинкой (`quote`) при 3-в-ряд схлопывают текст — 1–2 в ряд или картинка сверху; отзыв с подписью — `basic-card` (`title` имя · `text` цитата · `additionalInfo` роль · `icon` аватар), `quote` — для настоящего фото. `text` в runtime-конфиге рендерится литерально (markdown не работает). `companies-block` — одна картинка-полоса. Placeholder-SVG: `data:image/svg+xml,` + `encodeURIComponent` (не `btoa` — падает на кириллице) + XML-escape `&`, `<`.
