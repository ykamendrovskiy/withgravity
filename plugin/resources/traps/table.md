# traps/table — `@gravity-ui/table` (TanStack-обвязка)

Только за grouping / tree / DnD / настройку колонок; плоская таблица — uikit `Table` (официальный роутинг). Приоритет у `tsc`.

- **Импорты:** `ColumnDef` — из главного `@gravity-ui/table` (из `/tanstack` теряется `withNestingStyles` → TS2353); типы `Row`, `ExpandedState` — `import type … from '@gravity-ui/table/tanstack'`. В `cell` нет `info`: `cell: ({getValue}) => getValue()`. Пропа `width` нет (это uikit Table) — `attributes={{style:{width:'100%'}}}`; `stickyHeader` есть (verified 1.21.1 .d.ts).
- **Выбор строк — через `useRowSelectionFixedHandler`** (`{rowSelection, setRowSelection, tableData, getSubRows, getRowId}`) + `enableRowSelection` + **`enableMultiRowSelection: true`** (без него внутри группы чекбоксы как радио); при группах/дереве обязателен (TanStack #4878). Выбор непустой → массовые действия — `snippets/actions-panel-scroll-model.md`.
- **Per-row actions:** `getActionsColumn<TRow>('_actions', {getRowActions: (item, index) => TableActionConfig[]})` — 2 аргумента, `(item, index)`, не `{row}`; `'_actions'` добавь в `columnOrder`.
- **`useTableSettings({initialOrdering})`** — массив со ВСЕМИ id, включая `'_select'` и `'_settings'`, иначе служебные уедут в конец; либо не передавай `initialOrdering`.
- **Группировка — по официальному паттерну, не хэндролл:** union `Group | Leaf`, `getSubRows: (i) => 'items' in i ? i.items : undefined`, `getGroupTitle`, `enableExpanding` + `useState<ExpandedState>({})`. Полоса-заголовок группы рендерится только при `getIsGroupHeaderRow` (иначе per-cell режим, `getGroupTitle` мёртв); группы из `enableRowSelection` не исключай (каскад и indeterminate штатные); инсет вложенности — переменная `--_--depth-indicator-width`, не per-cell паддинги.
- **Фриз страницы от unstable refs** при ручной обвязке `useReactTable`: `useMemo` для state-массивов, `useCallback` для fn-пропов, effects от примитивов, не от `table`; проще — штатные хуки (`useTable`, `useRowSelectionFixedHandler`, `useTableSettings`).
- **Ширины и скролл:** `Table` рендерит голый `<table>` без scroll-контейнера (verified 1.21.1) — оберни только таблицу в `overflowX:auto` (контракт области — `data-scroll="intended"`), не рабочую область. Три класса колонок: поглотители (без `maxSize`), фикс-контент (`size` + `maxSize`), служебные (не трогать). Механика: `table.gt-table { table-layout: fixed }` + `width:auto !important` у `th` поглотителя (ступень-3 хак, узкий селектор, пометка версии) + **`min-width` на таблице** (сумма фикс + ~200), иначе поглотитель схлопывается в 0 на узких (verified 900/1600). С auto-layout `maxSize` на рендер не влияет.
