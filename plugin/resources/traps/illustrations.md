# traps/illustrations — `@gravity-ui/illustrations`

- **Использование:** named root-exports (`import {NotFound, NoSearchResults, InternalError, AccessDenied, SuccessOperation} from '@gravity-ui/illustrations'`), не deep-import и не `<Illustration name>`. `PlaceholderContainer.image` ждёт отрендеренный элемент `<NotFound/>`. Пустое / ошибка / успех — иллюстрацией, не растянутым `<Icon size={80}>`; экран результата — тот же `PlaceholderContainer` (`direction="column" align="center"`), не ручной Flex.
- **Покраска обязательна и по темам:** у пакета нет готового CSS, токены `--gil-color-*` задаются на `.g-root_theme_light` / `_dark` через приватные бренд-токены (`--g-color-private-brand-<N>-solid`); без покраски svg рендерится бесцветным/невидимым. Готовые миксины: `@import '@gravity-ui/illustrations/styles/theme.scss'` → `@include g-illustrations-colors-light` / `-dark` / `-light-hc` / `-dark-hc` на `.g-root&_theme_*`. Ручной набор (дефолтный бренд = `yellow`): object-base 550, hightlight (так в пакете) 350/700, accent-heavy 650/350, accent-light white-1000, danger red-550, shadow 650/500, lines 650, shapes 100/200 (light/dark).
