# Карточки шаблонов: источник и запись использования

**Карточка источника** (`templates/<id>/card.md`): id · назначение и «когда брать» · scale (app | screen | section) · версия и перечень
изменений по версиям · файлы и зависимости · контракт по масштабу (app: точка входа, владельцы провайдеров/роутера/темы, **адресация
экранов** — как открыть каждый экран; screen: маршрут, слоты shell, данные, состояния; section: props/события/слоты, кто владеет
состоянием и загрузкой, ограничения контейнера) · обязательные состояния и конвенции (id) · проверки (`check.id`).

**Запись использования `TemplateUse`** (`<папка потребителя>/card.md`, одна форма, поля по режиму):
```
templateId · mode: copy | import · consumer · contractRevision · verifiedAtRevision · дата
copy:   baseRevision · baseRef/files (хеши или ссылка на неизменную базу) · localChanges (что и почему)
import: module/export · resolvedVersion или lockRef
```
Сравнение (verify): copy — три стороны (база · копия · новая версия источника; diff копии с новым источником смешал бы адаптацию с
upstream); import — совместимость с разрешённой версией и контрактом. Хеш фиксирует изменение, не сохранность поведения. Слияние не
обещается; копии не обновляются сами.

Операции: взять (build: скопировать или импортировать с записью использования, адаптировать видимо) · изменить источник (profile: новая
версия + перечень) · сравнить (verify). Шаблон создаётся по явному запросу или по предложению при втором похожем экране.
