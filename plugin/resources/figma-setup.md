# Figma-скиллы — что нужно настроить

Для `figma-read`, `figma-write`, `figma-index`. Один раз на машину.

1. **Официальный плагин Figma для Claude Code** — `figma@claude-plugins-official` (команда `/plugin` → Figma, или
   `claude plugin install figma@claude-plugins-official`). Он подключает MCP-сервер `https://mcp.figma.com/mcp` и даёт скилл
   среды `figma-use`, без которого `use_figma` не вызывается.
2. **Вход в Figma** — при первом обращении к MCP откроется браузер, войти рабочим аккаунтом (OAuth). Токен (PAT) выпускать не нужно,
   в настройки ничего не вписывать.
3. **Доступ к файлам**: чтение (`figma-read`, `figma-index`) — роль viewer на исходном файле библиотеки или макета; запись
   (`figma-write`) — editor на целевом файле (свой драфт подходит). Доступ к пакету команды не даёт доступа к библиотекам —
   запрашивать у владельца библиотеки.
4. **Node.js** — для скриптов `figma-index`. Для перечисленных операций с Figma других установок не требуется.

Проверка перед первым запуском (три шага, каждый — своё условие):
- в сессии виден скилл `figma-use` и MCP-инструменты `use_figma` / `get_libraries`;
- `whoami` возвращает ваш аккаунт (вход выполнен);
- `use_figma` на нужном файле читает `figma.root.name` и `figma.variables.getLocalVariableCollectionsAsync()` — это проверяет доступ именно к этому файлу.
Отказ на любом шаге: первый — переустановить плагин; второй — повторить вход; третий — запросить доступ к файлу у владельца библиотеки (@ykmd для библиотек команды).
