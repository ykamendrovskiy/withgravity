# proposals.json — кандидаты в правила сервиса

Порученные изменения выполняются в согласованном объёме без повторного разрешения. Новые обобщения текущей задачи в общие
правила сервиса не активируются без решения пользователя: скилл пишет их в `proposals.json` проекта и показывает один список
в конце. Молчание = не применять (не «отклонено», не «забыть»).

Файл — объект `{"schemaVersion": "1", "proposals": [...]}` (не голый массив). Запись: `{id, event (откуда: second-similar-screen | so-intended | profile-code-mismatch | spec-conflict | feedback), scope,
delta (что предлагается записать и куда: profile | template | convention | exception), status (pending | accepted | rejected | superseded), created, resolved}`.
В новой сессии показываются только релевантные нерешённые, дедуп по правилу/области. «Так задумано» — локальное исключение,
ошибка проверки или решение команды: классифицируется, не становится конвенцией автоматически.
