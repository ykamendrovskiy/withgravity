# Каталог решений сервиса — формат

`catalog/` в корне проекта: индекс того, что уже есть и где лежит код. Код первичен, каталог указывает; опыт (грабли) сюда не пишется.

```
catalog/index.md   — генерируется из карточек (`node extract-catalog.mjs --index catalog/`); build читает целиком
catalog/<id>.md    — карточка: та же строка + код + раздел + ссылки
```
Строка индекса: `- **<id>** — \`<маршрут>\` · <задача одной фразой> · код: \`<файл, файл>\``; id — kebab-case с префиксом раздела
(`archetype-` · `block-` · `component-` · `data-` · `conv-`); разделы: Страницы · Каркас · Блоки · Компоненты · Модели контента ·
Источники данных · Как принято · Вне каталога.

Операции: бутстрап из репо — `node extract-catalog.mjs <repoRoot>` (Next.js pages + `src/{components,blocks,content,api}`; другие
фреймворки — вручную по формату); обновить — править карточку и пересобрать `--index`; проверить форму и дрейф (код не найден) — `--lint`;
перенести старый одиночный файл — `--from-legacy`. Не индексировать всё: 40–60 строк на сайт — норма; строка остаётся строкой.
Build: прочитать индекс, карточки выбранных единиц; построил новое — добавь карточку и пересобери индекс.
