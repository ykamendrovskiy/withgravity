  Перенести собранный на Gravity UI код (любой сборки, не только плагином) или шаблон команды в Figma-макет на настоящих
  инстансах кита: стили, переменные, состояния фреймами, отчёт переноса с классами расхождений и unresolved. Используй при
  «положи в Figma», «собери макет из кода», «обнови макет по коду». Требует Figma MCP (запись) и скилл среды figma-use.

> Экспериментально: проверяется на внутренних библиотеках команды (паспорта `libraries/figma/<id>/` пакета: `inventory.json` + `binding.json` с ключами); без пакета — только то, что отдаёт Figma MCP. Успех основного цикла build на это не переносится.
> Пререквизиты (плагин Figma, вход, доступы) — `../../resources/figma-setup.md`.
# figma-write
Вход: код на компонентах Gravity (происхождение не важно) · карта кит↔код (дефолт плагина — в `reverse.md`; карты сервиса — из
`libraries` пакета; Code Connect — как источник соответствий, поддерживаемое подмножество, остальное unresolved) · тема (если
есть) · карточки шаблонов (не обязательны — без них дефолты и строка «не найдено» в отчёте). Устройство кита ↔ код, откуда
ключи, принципы, самопроверка (сверка каждого итогового состояния с кодом) и отчёт переноса — `reverse.md` рядом.
Спрашивает: куда класть (файл/страница), если не сказано; `unresolved` — в конце номерами. Не меняет код.
