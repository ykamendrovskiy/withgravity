# catalog
Формат и правила — `../../resources/catalog/catalog-format.md`; операции — `node <плагин>/resources/catalog/extract-catalog.mjs`:
`<repoRoot> [--out-dir]` бутстрап · `--index catalog/` пересборка индекса · `--lint catalog/` форма и дрейф (код не найден) ·
`--from-legacy <catalog.md>` перенос. Экстрактор знает Next.js pages + `src/{components,blocks,content,api}`; другие фреймворки — карточки
вручную по формату. Скилл не квалифицирует единицы сам: фразы «что это» уточняются по коду, по просьбе пользователя — номерами.
Выход: `catalog/index.md` + карточки; в отчёте — сколько добавлено/обновлено/помечено дрейфом.
