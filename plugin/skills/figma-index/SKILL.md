# figma-index — опись и привязка библиотеки

## Вход
Ссылка на **исходный файл** библиотеки (не на файл-потребитель: его кэш отдаёт устаревшие ключи и значения) · папка пакета `libraries/figma/<id>/`
(есть — переиндексация; нет — создание, спроси `id` и роль одной строкой для `when.md`) · при необходимости — какие страницы пропустить
(Cover, Changelog, Archive, Deprecated — по умолчанию пропускаются по имени).

## Делает
1. `create_session` по ключу файла; чтение только через `use_figma` (скилл среды `figma-use`), ничего не менять: без `setCurrentPageAsync`
   на read-only файлах — узлы брать `getNodeByIdAsync`, страницы — `figma.root.children`.
2. Снять состав по страницам кодом из `extract.js` (шаблон: подставить id страницы и окно `OFFSET..LIMIT`): COMPONENT_SET и одиночные
   COMPONENT → имя, `key`, оси вариантов (VARIANT: имя оси → значения), свойства (TEXT / BOOLEAN / INSTANCE_SWAP / SLOT), число вариантов.
   Ответ канала ≤ 48 КБ → окна по ~300 сетов; тяжёлые страницы — по одной. Каждое окно сразу дописывать в файл
   `<папка>/.index/extract-<дата>.jsonl` (одна строка на сет) — не держать всё в контексте.
3. Текстовые и paint-стили, коллекции переменных (имена, моды, число переменных) — отдельным вызовом из `extract.js` (секция styles).
   Значения переменных по модам — секция variables по коллекциям, окнами ≈250 строк → `.index/vars-<дата>-<коллекция>-<n>.txt`
   (первая строка окна — `# collection=<имя> modes=a|b|c`; при желании сжать: `=path` для алиасов «@Appearance/<группа моды>/path»);
   затем `node <skill>/variables.mjs <папка> <окна...> [--ext <цели.txt> --ext-lib <префикс>=<libraryId>,… --ext-dir libraries/figma]` → `variables.json`
   (алиасы внутри файла — `@Коллекция/имя`; на внешние библиотеки — `@ext:<libraryId>/имя`, ключи целей — в `external` и в `binding.variables`
   той библиотеки; `@ext:?/…` — библиотека не сопоставлена; `@missing:…` — цель не найдена). Цели внешних алиасов снимаются отдельным
   окном (`name|key|префикс id коллекции`, секция ext в `extract.js`).
   Внешние алиасы: сначала ищи паспорт источника среди `libraries/figma/*/binding.json` (по ключу коллекции / `variableCollections`); если паспорта нет —
   спроси у владельца ссылку только на ту библиотеку, которая нужна текущей задаче (не на все зависимости разом). Палитру индексируй своим паспортом
   `libraries/figma/<id>/` (`variables.mjs … --init <id>`, окна в grouped-формате `prefix|leaf=hex,…`); без доступа к файлу — заготовка с ключами целей
   и пометкой «значения не сняты». Имя цели — подпись, не идентификатор: при одном имени у разных ключей (`ambiguous` в ответе секции ext) ссылка
   по имени не разрешается, merge переменных откажет — снять такие цели адресно по ключу.
4. `node <skill>/merge.mjs <папка> <extract.jsonl> [--styles <styles.json>]` → пересобирает `inventory.json` и `binding.json`, сохраняя
   ручные поля (logicalId, notes, codeMappingRef, tokens, dependencies, styles/variables-привязки, compatibility, themesExtract), печатает дифф
   и проверяет оба файла схемами. Дифф — по ключу и по имени: новые · исчезнувшие · переименованные (тот же ключ, другое имя) · изменились
   оси / свойства / число вариантов · изменился ключ при том же имени (перепубликация — отметить `status: ambiguous` до проверки).
5. Выборочная проверка публикации: 3–5 ключей через `importComponentSetByKeyAsync` / `importComponentByKeyAsync` в любом файле-потребителе
   (одиночные компоненты сетом не импортируются — пробовать оба); несовпадение → `status: unresolved` у записи; после проверки — перезапуск merge с `--verified`
   (иначе `lastVerifiedAt` не меняется). Запись `ambiguous` (ключ сменился при том же имени) держится между прогонами, снимается `--confirm-keys <key,key>` после проверки каждого (или `all` — только если проверены все).
   Коллизии `logicalId` merge разрешает суффиксом по ключу и печатает `reId` — миграцию ссылок (codeMappingRef, профили) делать по этому списку. Приватные сеты (префикс «.» или «_»)
   merge помечает `unresolved` сам: Figma их не публикует, проверять импортом не нужно.
6. Сдача: число сетов / одиночных / иконок, дифф по классам, `indexedAt`, переменных и внешних алиасов, что не снято (Code Connect).
   Паспорт коммитит владелец пакета; `when.md` не переписывать без поручения.

## Не делать
Не индексировать через `search_design_system` (20 соседей на запрос, нет полноты) · не читать файл-потребитель вместо исходника ·
не придумывать `logicalId` заново при переиндексации (берётся из прежней описи по ключу, затем по имени) · не менять файл библиотеки.
