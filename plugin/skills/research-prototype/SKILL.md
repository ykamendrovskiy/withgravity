# research-prototype
Читает: `scenarios.manifest.json` (если есть), карточку экрана, каталог `../../resources/states.json`, принятые в build состояния.
Обязательные для обещанного поведения состояния уже сделаны в build — здесь объём **исследовательских** сценариев, который
выбирает человек: предложи чек-листом применимые по признакам (`../../resources/facts.md`), не навязывай.

Делает: манифест по `../../resources/scenarios.md` — каждый сценарий как путь: пресет данных · начальное состояние · действия ·
ожидаемые переходы/результат · сброс (не снимок «error», в который реальный submit не попадает); панель прототипа (dev-only,
`VITE_SCENARIOS=1` для гейта), deep link `?scenario=`, сброс без перезагрузки, режим респондента по запросу.
Состояние, недостижимое реальным потоком (только подменой), — предложить добавить обработку в код, не подменять.
Проверка: `../verify/SKILL.md` обходит сценарии из манифеста.
