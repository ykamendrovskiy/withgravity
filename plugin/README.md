# withgravity — сборка «как принято» на Gravity UI поверх официального скилла

Плагин для Claude Code. Корректность компонентов (пакет, версия, API, typecheck) ведёт официальный скилл
[`gravity-ui`](https://github.com/gravity-ui/skills) — он обязателен. Плагин добавляет контекст сервиса и дисциплину приёмки:
профиль сервиса, шаблоны команды, записи конвенций и состояний с предикатами, план приёмки, проверку с честными статусами.

**Скиллы:** `build` (новый проект · новая страница · локальная правка · смена темы/обвязки) · `research-prototype` (состояния, панель, deep link) ·
`profile` (создание интервью / обновление по поручению, машинная валидация) · `verify` (гейт + план приёмки + сравнение копий шаблона) ·
`catalog` · `feedback`. Алиасы 0.7.x: `create` → build, `synthesize-profile` → profile, `write-back` → feedback + profile.

**Установка:** плагин (`--plugin-dir` или marketplace) + официальный скилл: `npx skills add gravity-ui/skills`; для надёжной
авто-активации вставь блок «Activation tip» из README gravity-ui/skills в `AGENTS.md` проекта. Полная проверка требует Playwright
(`npm i -g playwright && playwright install chromium`); без него гейт честно работает в static-only.

**Модель:** `resources/model.md`. Что считается проверенным — `skills/verify/harness/HARNESS.md`.

## Известные ограничения и экспериментальное
- Три проверки из конвенций без автоматической реализации (`panel-last-row`, `inner-scroll`, `icon-only-tooltip`) — статус `not-run`,
  закрываются скриптом агента или человеком с записью в `gate-out/evidence.json`.
- Известные ограничения библиотеки применяются только при установленной версии в диапазоне записи; иначе находка обычная.
- Figma-конвейер (чтение макета → спецификация → сборка; перенос в Figma) — вне поставки до приёмки; данные библиотек команды — в пакете
  профиля, не в плагине. Профили из кода/макета, индексация своих библиотек — экспериментально.
- Проверено на Vite-проектах; Next.js/Remix — гейт по URL без скаффолда.

## Что изменилось относительно 0.7.4
Онтология вместо гайдов: `conventions.json`/`states.json` с предикатами, `acceptance-plan.json`, `checks.json`, `known-limitations.json`,
`validate.mjs` профиля, TemplateUse-карточки; грабли сжаты до одного файла на пакет (дубли официального скилла удалены); registry и
AGENTS.md сняты. Прежний формат пакета профиля (`blocks/` + `archetypes/`) читается как шаблоны.
