# Changelog

## 0.9.11 — 2026-10-21
- build: раздел вопросов переписан — сначала что и как спросить (опции с дефолтом), запреты в конце; источник кастомной темы — второй вопрос в том же вызове с опциями «тема из проекта рядом <путь>» · «CSS/JSON из Themer» · «базовый цвет». ## 0.9.10 — 2026-10-21
- build: при «кастомной теме» источник спрашивается отдельным вопросом ровно тремя опциями (готовая тема из проектов рядом · CSS/JSON из Themer · базовый цвет); цвета-пресеты запрещены — в прогоне плагин сразу предложил «изумрудный/индиго/янтарный».

## 0.9.9 — 2026-10-21
- Удалены скиллы-алиасы `create`, `synthesize-profile`, `write-back`: у нового плагина нет пользователей со старыми именами, а в поставке не должно быть ничего необъяснимого. Скиллов шесть: build · research-prototype · profile · verify · catalog · feedback.

## 0.9.8 — 2026-10-21
- build, вопросы на входе: кастомная тема — сначала готовые темы из соседних проектов, затем Themer-экспорт CSS/JSON (gravity-ui.com/themer), затем базовый цвет; режимы проверки с ценой по времени (полная — самая долгая); второй вызов после таблицы признаков — чек-лист исследовательских состояний и панель прототипа (дефолт «да» для прототипа/демо).

## 0.9.7 — 2026-10-21
- Уточнения по замечаниям владельца: тема из цвета — перенос бренд-группы нужен именно при генерации библиотекой (веб-Themer делает его сам), text-brand-contrast — решение автора темы, плагин только предлагает по APCA; uikit Progress во flex-колонке схлопывается из-за `margin: 0 auto` (трап).

## 0.9.6 — 2026-10-21
